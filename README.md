# 九格手记 · Windows 桌面版

> **仓库已公开，欢迎参与完善**（2026-11-15）。参与前请先读 [CONTRIBUTING.md](CONTRIBUTING.md) 与 [项目现状](docs/CURRENT-STATE.md)。
> ⚠️ **本 README 是 v1 版本快照**：文中「纯本地零网络 / 不联网」等描述已不适用于当前主线（v2 渲染层 + V3.17），请以代码与项目现状为准。
> 仓库尚未选定开源许可证；许可证明确前请勿直接再分发或商用集成。

把手机上的「九格手记」搬到电脑：**不联网、不登录、不上传**，日记只存在这台电脑的一个文件里。
打开就是「今日」页，写九格、记一笔收支、封一封给未来的信，都和手机上一模一样。

---

## 一、两种启动方式

| 方式 | 怎么做 | 适合谁 |
|---|---|---|
| **免安装（推荐）** | 双击 `build\九格手记-便携版.exe` | 绝大多数人。不用安装、不写注册表，把 exe 拷到别的电脑也能用 |
| 安装版（可选） | 双击 `build\九格手记-安装版-1.0.0.exe`，按提示选目录 | 想要桌面 / 开始菜单快捷方式的人 |
| 源码启动（开发用） | 双击 `scripts\start.bat`（需先在本目录执行过 `npm install`） | 想改代码或跑自检脚本的人 |

> 第一次打开会直接落在「今日」页。左侧竖栏是 **今日 / 回看 / 胶囊 / 坚持 / 设置** 五项。

---

## 二、数据放在哪里

- 所有日记、未来胶囊、学习库、皮肤与模块开关，都放在一个文件里：
  `C:\Users\<你的用户名>\AppData\Roaming\jiuge-desktop\jiuge-desktop\store.json`
- 想直接打开这个文件夹：菜单 **「文件 → 打开数据目录」**。
- 卸载或重装程序**不会删掉**这个目录；但**换电脑、重装系统之前，请先导出一份备份**。
- 直接点窗口右上角 × 退出时，正在输入但还没点保存的工作感想、今日一句、当前格正文都会自动存下来，不会丢字。

---

## 三、从手机迁移（导入备份）

1. 在手机小程序里导出 JSON 备份，把文件放到电脑上。
2. 桌面版：**设置 → 数据管理 → 「导入小程序备份文件（v6/v7）」**。
3. 选好文件后会提示「检测到 N 篇日记。导入只补写本机没有的日期，不会覆盖已有记录。」，点「开始导入」即可。
4. **可以取消**，取消不会写入任何数据。
5. 兼容 **v6 / v7** 备份，也兼容**没有版本号的老备份**（老备份只导入能识别的部分，会提示「旧版备份」）。
6. 原来那行 **「从剪贴板导入」仍然在**，两条入口用的是同一套导入规则：本机已经写过正文的日子绝不被覆盖，只是空壳的日子才允许补写。

## 四、导出：另存为文件 vs 复制到剪贴板（别弄混）

| 想要什么 | 去哪里 | 得到什么 |
|---|---|---|
| **导出成看得见的文件**，存到 D 盘 / 移动硬盘 | 菜单 **「文件」** 里的三项：`导出可读文本`、`导出 Markdown`、`导出 JSON 备份`；或按 **Ctrl+E**（默认导出 JSON 备份） | 弹出保存对话框，选好位置后写出 `九格手记-备份-YYYY-MM-DD.json` / `.md` / `.txt` |
| 复制一段文字，贴到微信 / 笔记软件里 | **设置页 → 数据管理** 里的「导出可读文本」「导出 Markdown」「导出 JSON 备份」三个按钮 | **复制到剪贴板，不生成文件** |

> 设置页那三个导出按钮仍然是「复制到剪贴板」，和小程序完全一样；**要存成文件请用「文件」菜单（或 Ctrl+E）**。
> 三种格式的内容和小程序导出的内容一致（只差导出时间戳）。`JSON 备份` 用于日后导入还原，桌面版导出的版本号是 **7**。

## 五、快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl+S` | 保存当前格 |

## 六、四套皮肤与三个功能模块开关

- **界面皮肤**四套（设置页最上面）：标准版 · 森绿米白 / 科技蓝 · 冷调夜航 / 少女版 · 樱花奶油 / 儿童版 · 糖果积木。点一下就换，标题栏、侧边栏、主区**一起变色**。
- **功能模块**三个开关（设置页）：工作看板、记一笔收支、学习进展。**关掉只是不显示面板，写过的数据一条都不删**，随时开回来就能看到旧内容。
- 「头七天引导」也有一个开关；设置页里还有四套页面模板可以切换（只换标签与提问，不动已写的内容）。

## 七、第一次运行可能被 Windows 拦一下

这个 exe **没有购买代码签名证书**，Windows SmartScreen 可能弹出「Windows 已保护你的电脑」：

1. 点 **「更多信息」**
2. 再点 **「仍要运行」**

这是未签名程序的正常提示。本程序不联网、不上传、无账号、不做内容分发。

## 九、断网也能用 · 已知口径

- **纯本地零网络**：全项目没有任何 HTTP / WebSocket 请求、没有账号、没有上传、没有遥测、没有自动更新器；运行时不依赖任何第三方库。界面、样式、名言库、五页代码全部随 exe 打包在本地 `app.asar` 里，通过 `file://` 加载。
  验证打包产物启动时的日志里，所有资源路径都是 `file:///C:/Users/.../Temp/jiu-ge-desktop/resources/app.asar/...`，**没有任何远程地址**；`npm run verify` 的零网络关键字扫描也是 0 命中。所以**拔不拔网线都一样能写日记**（这里没有假装真的拔网线，是靠代码扫描 + 依赖清单 + 启动日志三条证据）。
- 以下行为是从小程序**原样搬过来、本次不修改**的：
  - 九宫格前 4 格有红星，但保存时不校验；
  - 「反复出现的字句」会切出断词；全年像素年历一次渲染 372 格；
  - **导出 Markdown 用「该篇当时所用模板」的栏目名，而搜索结果用「标准栏目名」**，两种叫法不一致（保持现状，不是 bug）；
  - 学习库整体存在一个键里；
  - 界面里「日记只存在这台手机上」等带手机语境的文案**逐字保留**，没有改成「电脑」。
- 金额一律以**分**为单位；日期键一律 `YYYY-MM-DD`（本地时区）。

## 十、开发机宿主环境提示（给测试 / 开发同学）

这台开发机上的 WorkBuddy 会注入 `ELECTRON_RUN_AS_NODE=1`，在这个环境里**直接敲 `npm start` 会报 `app.whenReady undefined`**（Electron 被当成纯 Node 跑了）。

- `scripts\start.bat` 已经显式清空该变量，**双击它不受影响**；
- 命令行手动验证时先执行 `env -u ELECTRON_RUN_AS_NODE npm start`（Git Bash），打包后的 exe 同样需要先清这个变量。
- 自检命令（纯 Node，不需要 GUI）：
  - `npm run verify` — 69 项等价性与全局一致性（含 T5 打包交付 6 项）
  - `npm run smoke` — 28 项数据层 / 导入契约冒烟
  - `npm run bench` — 200 篇日记读放大基线
- 测试钩子 `JIUGE_TEST_PROBE` / `JIUGE_TEST_READBACK` / `JIUGE_TEST_CLOSE_MS` 只在显式设置环境变量时启用，正式使用默认关闭。
