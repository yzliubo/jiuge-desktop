## 1. 产品目标与本次增量范围

| # | 目标（正交） | 衡量方式 |
|---|---|---|
| G1 | **等价**：Windows 版 5 页功能与小程序逐点一致，同一份数据算出同一结果 | 逐页功能对照表（§4）全部通过；同一 v6/v7 备份在两端导入后 `writtenDates()` 完全一致 |
| G2 | **可迁移**：把手机上的历史日记一次性、无损、不覆盖地搬到桌面 | 新增「导入小程序备份文件」入口；冲突策略与 §5 一致；导入结果有明确反馈 |
| G3 | **纯本地**：桌面形态下继续守住零网络、零账号、数据只在本机 | 全链路无 HTTP/WS 请求；数据落盘在 Electron `userData`；导出的文件由用户自行保管 |

### 本次增量边界（一句话）

> **只换「壳」与「存储/文件 I/O」，不换「脑」**：`app.json` 的 tabBar、微信原生 API、剪贴板导出、手机尺寸布局被替换/适配；`utils/` 里 8 个模块的业务算法、数据结构、文案、判定口径全部原样保留。唯一新增的产品能力是**从本地文件导入小程序备份**。

| 变更类型 | 内容 |
|---|---|
| 替换 | `wx.getStorageSync/setStorageSync/removeStorageSync/getStorageInfoSync` → 本地持久化适配层；`wx.showToast/showModal/showActionSheet` → 桌面提示/对话框；`wx.setClipboardData/getClipboardData` → Electron clipboard；`picker mode=date` → 桌面日期控件；tabBar 图标与原生导航栏 → 应用内导航 + CSS 主题 |
| 适配 | 触摸滑杆 → 鼠标拖拽；`globalData` 跨 tab 带参中转 → 应用内状态直传（行为等价）；`onHide/onUnload` 落盘 → 窗口关闭前 flush |
| 新增 | 「导入小程序 v6/v7 备份文件」（原生文件选择对话框）；导出另存为文件；应用菜单与快捷键（P1）；窗口尺寸/位置记忆（P1） |
| 不变 | 全部业务算法、9 个数据键、模板/皮肤/模块开关/引导/里程碑、备份格式与冲突策略、5 条 P1、纯本地零网络 |

| 条件 | 行为 |
|---|---|
| `typeof version === 'number' && isFinite(version)` | `sourceVersion = floor(version)` |

### 5.4 冲突策略（原样保留，不得改写）

| # | 规则 | 判据 |
|---|---|---|
| 1 | 本机该日 `hasContent(local) === true` → **跳过**，绝不覆盖用户当前数据 | 有正文的日子导入前后字节不变 |
| 2 | 本机该日**只是空壳**（点开过、一个字没写）→ 允许备份补写 | 空壳日被正确补上 |
| 3 | 配置类（`startedAt/template/modules/milestones/reviews`）**本机已有值才不写**；且**必须先于写日记执行**（否则 `save()` 会把 `startedAt` 补成第一篇写入日期，启程天数凭空少几天）；写完 `invalidateMemo()` | 换机后启程天数、模板、模块开关、里程碑、复盘答案与手机一致 |
| 4 | 学习库按 **id 合并**：只补本机没有的条目与主题；条目引用了不存在的 `topicId` 时置空 | 已有进展不被覆盖 |
| 5 | 胶囊按 **id 去重**合并；`openAt` 非 `YYYY-MM-DD` 的跳过 | 重复导入不产生重复信件 |
| 6 | 写成功后**回读并 `hasContent` 复核**：`imported` 只计真实正文篇数；空壳计 `emptyShell` 并同时计入 `skipped` | 导入篇数不虚高 |
| 7 | `hasContent()` 只认字符串；`workBoard/moneyBook/studyLog` 任一有内容也算一篇 | 脏数据不虚增连续天数与导出条数 |
| 8 | 落盘裁剪：单格 ≤2000、基础栏 ≤200；导入同样裁剪 | 超长文本被稳定截断 |

### 5.6 「v6 备份」口径澄清（重要，需主理人确认）
